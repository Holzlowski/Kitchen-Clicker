**Kitchen Clicker** is a light-hearted, pizza-themed clicker/idle game built in Unity. Players top rotating pizzas with the right ingredients using their mouse, earn money for every successful order, and upgrade their kitchen over time.

## 🎮 Gameplay Overview

- 🍄 **Top the Pizza!**  
  Click at the right time to add ingredients to a rotating pizza base. Get the topping combo right to finish the order.

- 💸 **Earn & Upgrade**  
  Earn money with every pizza you complete. Spend it on:
  - 🔧 **Upgrades** that improve your speed or earnings.
  - 👨‍🍳 **AI Chefs** that automate pizza-making while you're away or focused on upgrades.

- 🏆 **Progression System**  
  Unlock new ingredients, faster pizza rotations, and more efficient helpers as your kitchen grows.

## 🛠️ Built With

- Unity Engine
- C#
- Custom ingredient/topping logic
- Basic UI for upgrades and income tracking

## 📚 Development Focus

The goal of this project was to explore:
- Clicker/idle game mechanics
- UI systems for upgrades and automation
- Balancing active vs. passive gameplay
- Fun, food-themed visual feedback

---

This small project was a fun experiment in combining **clicker gameplay with resource management and automation** – and who doesn't love pizza?
